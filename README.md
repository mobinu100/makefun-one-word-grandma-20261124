The single word a grandma would text about AI, written to `/output/entry.txt` by `main.ts` (Node 22, deterministic, copy-only, no network).

> robit

Her own spelling of robot: warm, a little baffled, tied to the machine itself, and funny with no caption at all. One word, five letters, no punctuation tricks.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
